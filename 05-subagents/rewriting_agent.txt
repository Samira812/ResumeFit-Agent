REWRITING SUBAGENT

Purpose:
Generate a tailored resume using:
   - cv_text
   - job_description_text
   - scoring_data (JSON from scoring_agent)
   - guardrails

Inputs:
   - cv_text: extracted text from the user's CV file.
   - job_description_text: job description text or file content.
   - scoring_data: JSON object containing matched_keywords, missing_keywords, extra_keywords, match_percentage.

Steps:
1. Identify relevant content:
   - Extract all sections from cv_text (summary, skills, tools, experience, projects).
   - Identify which items match job_description_text using scoring_data.matched_keywords.
   - Identify irrelevant items using scoring_data.missing_keywords.

2. Remove irrelevant content:
   - Remove projects, experience, skills, tools, or achievements that do not match job_description_text.
   - Only remove content that exists in the CV.
   - Do not remove identity details, job titles, dates, or essential career history.

3. Rewrite summary:
   - Create a new summary aligned with job_description_text.
   - Use only information from cv_text.
   - Highlight matched keywords.
   - Do not invent experience or skills.

4. Reorder skills and tools:
   - Place matched skills first.
   - Place partially matched skills second.
   - Place irrelevant skills last or remove them if allowed.

5. Reorder experience:
   - Move relevant experience to the top.
   - Keep chronological order inside each job.
   - Rewrite bullet points to emphasize matched keywords.
   - Do not invent new responsibilities.

6. Reorder projects:
   - Move relevant projects to the top.
   - Remove irrelevant projects if allowed by guardrails.
   - Rewrite project descriptions using only CV content.

7. Generate final resume text:
   - Preserve identity details exactly.
   - Preserve job titles and dates exactly.
   - Ensure formatting is ATS-friendly.
   - Ensure the resume is clean, structured, and professional.

8. Return structured output:
   {
     "summary": "...",
     "skills": [...],
     "tools": [...],
     "experience": [...],
     "projects": [...],
     "match_percentage": scoring_data.match_percentage
   }

Rules:
   - Do not invent experience, skills, or achievements.
   - Do not modify identity details.
   - Do not hallucinate.
   - Only use content that exists in the CV.
   - Removal is allowed only for irrelevant content.
   - Rewriting must be based strictly on CV content.
   - Tailoring must align with job_description_text.
